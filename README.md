# Smart Home Intruder Alert System

## Project Description
This project utilised a raspberry pi so that, when armed, it will sense movement and take a picture of the intruder while also logging the time of the break-in. 
It will display a warning on the Sense HAT's LEDs and send a message through email, push notification using Blynk. 


## Planned Features

- Arm/disarm monitoring mode
- Detect movement using the Sense HAT accelerometer
- Capture intruder's image using Pi Camera
- Save event data with timestamp
- Display BREAK-IN warning on Sense HAT
- Store event history locally as JSON
- Show latest event on a Flask dashboard
- Cloud alert and Blynk notification
